  1. 설치
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  [방법 A] setup.exe — GUI 위자드 (추천)
    1. https://github.com/bernakilljos/orchestration/releases
    2. OrchestrationKit-Setup.exe 다운로드
    3. 더블클릭 → 경로 선택 → 컴포넌트 선택 → 설치
    4. 완료 후 Claude 자동 실행 옵션

  [방법 B] git clone — CLI
    git clone https://github.com/bernakilljos/orchestration.git
    cd orchestration
    setup\setup.bat C:\work\myproject

  [방법 C] 사일런트 — 자동화/스크립트용
    OrchestrationKit-Setup.exe /VERYSILENT /DIR="C:\work\myproject"

  [서비스만 재시작]
    install.bat restart

  3. 기본 사용법
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  [일반 사용 — Claude에게 말하면 됨]
    "로그인 페이지 만들어"
    → Claude가 설계 → task-instruction.md 작성
    → Codex가 구현 → Claude가 보완 → Gemini가 검증

  [수동 실행]
    codex-a --auto           Codex가 지시서 읽어 구현
    gemini-a --verify        Gemini가 결과 검증
    claude-auto              Claude 병렬 워커 (Sonnet+Opus)

  [병렬 실행 — N개 워커]
    codex-auto               10개 워커 (기본)
    codex-auto 20            20개 워커
    gemini-auto              10개 검증자 (기본)
    gemini-auto 5            5개 검증자
    claude-auto 30           30개 Claude 워커

  [중단]
    .claude\tasks\stop 파일 생성 → 모든 워커 즉시 종료
    또는 /loop-stop 명령

  4. AI 역할 분담
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ┌──────────┬───────────────────────────────────┐
  │    AI    │              역할                 │
  ├──────────┼───────────────────────────────────┤
  │ Claude   │ 팀장: 설계, 판단, 승인, 보완      │
  │          │ + 문서/기획/디자인 (Gamma, Canva)  │
  ├──────────┼───────────────────────────────────┤
  │ Codex    │ 구현: 500줄+ 코드 1차 구현        │
  │          │ codex-a --auto로 실행              │
  ├──────────┼───────────────────────────────────┤
  │ Gemini   │ 검증: 코드 리뷰, 보안, 문서화     │
  │          │ gemini-a --verify로 실행           │
  └──────────┴───────────────────────────────────┘

  [Advisor 모드]
    claude-auto 실행 시 자동 적용:
      실행 모델: claude-sonnet-4-6 (빠르고 저렴)
      조언 모델: claude-opus-4-6 (복잡한 판단)
    수동: claude --model claude-sonnet-4-6 --advisor claude-opus-4-6

  5. 파이프라인
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  [표준 파이프라인]
    요청 접수
      → init (스택 감지, 폴더 생성)
      → research (파일 탐색, 리스크 식별)
      → team-lead (task-instruction.md 작성)
      → Codex 1차 구현 (codex-a --auto)
      → Claude 보완/고도화
      → Gemini 검증 (gemini-a --verify)
      → Claude 채택 → 배포

  [AI Handoff — 강제 인수인계]
    Claude → Codex:  task-instruction.md + handoff-log.md 필수
    Codex → Claude:  implementation-report.md 필수
    Claude → Gemini: verify-*.md + 검증 포인트 필수
    Gemini → Claude: review-result.md (합격/불합격) 필수
    ※ 산출물 없으면 다음 단계 차단 (hook-08)

  [워커 종료 조건 — 3중]
    1. .claude\tasks\stop 파일 → 즉시 종료
    2. heartbeat 5분 미갱신 → Claude 종료 감지 → 종료
    3. 태스크 없이 1시간 대기 → 자동 종료

  7. 대시보드
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  시작:
    dashboard.bat    → http://localhost:8787 + cloudflared 터널

  기능:
    - 멀티 PC 실시간 상태 모니터링
    - 원격 화면 캡처 + 리모트 컨트롤
    - 태스크 상태 (대기/실행/완료)
    - 원격 태스크 전송
    - RDP 원클릭 연결

  통신 방식 (자동 선택):
    1순위: cloudflared 터널 → HTTP 직접 통신 (실시간)
    2순위: git push fallback (30초 간격, 방화벽용)

  9. 트러블슈팅
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  [한글 깨짐]
    → install.bat 재실행 (UTF-8 자동 적용)

  [codex-a / gemini-a 못 찾음]
    → install.bat 재실행 또는
    → .claude\scripts\codex-a.bat 직접 실행

  [MCP 서버 누락]
    → claude mcp list로 확인
    → 수동: claude mcp add -s user context7 -- npx -y @upstash/context7-mcp

  [hook 에러 — "No such file"]
    → .claude\settings.json에서 없는 hook 파일 참조 제거
    → 최신 settings.json: git pull로 업데이트

  [워커가 안 꺼짐]
    → .claude\tasks\stop 파일 생성: echo stop > .claude\tasks\stop
    → 또는 /loop-stop 명령

  [대시보드에서 PC가 안 보임]
    → wscript "%USERPROFILE%\.claude\status-push-silent.vbs"
    → 또는 install.bat restart

  [설치 로그 확인]
    → type %TEMP%\orchestration-install.log
    → type %TEMP%\orchestration-setup.log
