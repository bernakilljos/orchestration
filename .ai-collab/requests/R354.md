5. 실험: PARTIAL 출판 후 실제 사용자 재개, 중단 후 세션 재시작, 20분 지나도 불필요한 wakeup 없음, 같은 요청 두 번 소비하지 않음, 신규 요청과 리뷰 도착, 완료 시 안전한 ack, git push 실패, 새 커밋 후 원장 최신성. 격리 fixture에서 before/after 실패 증거.
