# R364 보고 — 사용자 지시 이행 신뢰성: 반복·교착 결함 실증 수정

## 0. 결론
- 같은 상태에서 같은 안내·재시도·재전달을 반복하던 결함을 승인 게이트 밖에서도 찾았다. 확정 결함 6건(조사 5건 + 수정 중 발견 1건) 가운데 **4건을 코드로 고쳤다**(수정 전 FAIL → 수정 후 PASS). 2건은 기존 설계(R335)와 맞물려 있어 이번에는 고치지 않고 기록만 했다.
- 사용자 목표(System32\powershell 삭제)는 **미완료**다. 관리자 권한(UAC)은 사용자 동작이 필요하다(R363 보고서 참조). 이 차단 때문에 다른 작업을 멈추지는 않았다.

## 1. 원인 그래프 (실제 연결만)
사용자 프롬프트 → `prompt-dispatch.py`(ledger 등록·주입 훅들) → 모델 계획 → `tool-dispatch.py pre`(승인 게이트 `approval_gate_detect.run` → `approval-gate.py` scope_key·find_request·new_request·consume_approval) → 실제 도구 → `tool-dispatch.py post`(결과 기록 record_result) → Stop(`tool-dispatch.py stop` → 원장 게이트·standing·six-guards + 비동기 15종: `auto-save-next-actions`·`supervisor active` 포함) → 다음 세션 SessionStart(`resume-last-24h`가 next-actions 주입) · 별도 루프 `ai-collab-report.py poll/wait`(20분 임대 재전달).
