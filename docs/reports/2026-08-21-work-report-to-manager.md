## 2. 어려운 점

### 개인 병목
- 3축 (내부회계·RMS·연결결산) 을 혼자 커버 → 하루 각 프로젝트에 2~3시간이 실질 한계
- 백업 개발자 부재 → 부재 시 진행 정지

### 기술 부담
- **개인정보·기업 민감정보 처리 리스크** — RMS I/F 데이터 (법인카드·자금·구매) 를 외부 AI API 로 보내면 규제 리스크 발생 → **로컬 AI (사내 GPU) 필수인데 미보유**
- 2026 하반기 AI 신기술 파도 (매주 릴리스) 학습·킷 반영 부담

### 도메인 공백
- **회계 정합성** — 회계법인 영역 · 팀 자체 커버 X → 외주 필요

### 사내 개발 환경
- **사내 개발 표준 환경·공용 CI/CD 부재** → 프로젝트마다 인프라 세팅 반복 · 시간 소모

## 3. 건의사항

1. **백업 개발자 1명 배치** — RMS 또는 연결결산 중 최소 1개 부담 완화 · PL 부재 시 진행 정지 리스크 제거
2. **사내 GPU 서버 도입** — RMS I/F 데이터 (법인카드·자금·구매) 를 외부 API 미노출 조건에서 처리 · 규제 대응 + API 원가 절감 이중 효과 · 로컬 모델 Qwen 3.8-27B (Apache 2.0) 검증됨
3. **우선순위 결정 요청** — 신사업 (RMS·ICM Agent Go) vs 유지보수 (연결결산) 리소스 배분 · 개발팀이 무엇을 먼저 완비할지 팀장님 판단 필요

## 4. 향후 1~2년 계획

> 개발이 만들지 않으면 아무도 팔 수 없음. 시기별 목표·매출 연결·팀장님 지원 필요 시점을 함께 정리.

| 시점 | 개발 목표 (측정 가능) | 매출·실적 연결 | 팀장님 지원 필요 |
|---|---|---|---|
| **2026 Q4** | 프로토타입 3종 완성 — ① RMS 신사업 (I/F 시나리오 3: 법인카드·자금·구매) ② ICM Agent Go (mem0·RAG·RPA) ③ 연결결산 클라우드 알파 | RMS **유료 검증 (PoC) 3~5곳** 시작 | **백업 개발자 배치** (Q4 초) — 부재 시 진행 정지 리스크 제거 |
| **2027 상반** | 정식 릴리스 2종 — ① RMS 정식판 ② ICM Agent Go 정식 · 컨설팅 진단 툴 세트 | RMS **유료 고객 5+ 확보** · 기존 내부회계 고객 **프리미엄 옵션 판매** · **컨설팅 매출 신규** | **사내 GPU 서버 도입** (Q1) — 로컬 AI 로 규제 대응 + API 원가 절감 |
| **2027 하반** | 확산 · 파트너 채널 · 규제 대응 세트 (정보보호공시·ESG 공시·K-SOX 강화) | **파트너 재판매** 개시 · **규제 대응 신규 상품 라인** | **신사업 vs 유지보수 우선순위 재검토** (Q3) |
| **2028+ 대비** | ① 정보보호공시 자동화 (자산 100억↑ 확대 규제) ② 양자내성보안 (RMS 다차원) ③ 합성 데이터 (RMS 학습용·개인정보 우회) | 규제 시점에 맞춘 **시장 선점 상품** | 2027 하반 로드맵 승인 |

### KPI 관리 지표 (팀장님 면담용)

- **개발 완성도**: 프로토타입 3종 (2026 Q4) → 정식 2종 (2027 상반) → 파트너 자료 (2027 하반)
- **매출 씨앗**: 2026 Q4 유료 검증 3~5곳 → 2027 유료 고객 5+ → 2027 하반 파트너 매출
- **원가 개선**: 사내 GPU 도입 후 AI API 원가 비율 관측 (2027 Q1~)
- **리스크**: 개인 병목 (백업 개발자 배치 전) · 로컬 AI 미보유 (GPU 도입 전) — 두 리스크는 팀장님 지원으로 해소 가능
