## 2. 발견된 문제와 처리

###  P1. install_*.bat 가 LF only (cmd 호환성)
**증상**: 사용자 직접 cmd 실행 시 `'nstall_gemini.ps1' is not recognized` + `'지를' is not recognized`
**원인**: 이전 commit `3ca6521`/`90f42fb` 의 install_codex/gemini.bat 가 **LF 줄바꿈**으로 저장됨. cmd.exe 가 한글 multi-byte byte 시퀀스와 LF 만 있는 line break 를 혼동해 wrapper path 의 첫 글자(`i`) 잘림.
**처리**: PowerShell 로 모든 install_*.bat → CRLF 일괄 변환 + 재검증 통과. (현재 commit 에 포함)

###  P2. .claude/ 에 orphan 17개 (drift)
**증상**: `bash .claude/scripts/sync-plugins.sh --check` 에 17개 orphan 보고
**목록**:
- commands (16): `10x.md`, `artifacts.md`, `auth.md`, `brief.md`, `check-services.md`, `compare.md`, `critique.md`, `devil.md`, `example.md`, `explainlikeim5.md`, `ghost.md`, `install-mcp.md`, `ooda.md`, `pitch.md`, `scout.md`, `teacher.md`
- skills (1): `skill-example.md`
**원인**: `.claude/commands` 에 있으나 `plugins/<name>/commands/` 에 원본 없음. 외부 plugin 또는 글로벌 sync 의 잔재로 추정.
**해결 옵션**:
- A. `bash .claude/scripts/sync-plugins.sh --prune` (일괄 삭제, 16개 명령 사라짐)
- B. plugins/<적절한_플러그인>/commands/ 로 이동 (어느 플러그인 소속인지 결정 필요)
- C. 그대로 두기 (orphan 경고만 남음)
**판단**: 사용자 지시 받기 전엔 안전하게 유지 (`C`)

###  P3. plugins/exec_orch hooks .sh 파일 6개 누락
