## 단계별 흐름

```
  ┌──────────────────────────────────────────────┐
  │ 1. /exec_remote-setup                        │
  │    Oracle Free Tier 가입 + ARM A1 VM 생성    │
  │    (사용자 액션 필요: 카드 등록·SMS 인증)    │
  └─────────────────┬────────────────────────────┘
                    │ Public IP 받음
                    ▼
  ┌──────────────────────────────────────────────┐
  │ 2. /exec_remote-ssh                          │
  │    gen-ssh-key.sh (ED25519)                  │
  │    ~/.ssh/config 자동 등록                   │
  │    공개키 → Oracle 콘솔 붙여넣기             │
  └─────────────────┬────────────────────────────┘
                    │ ssh orch-vps 접속 OK
                    ▼
  ┌──────────────────────────────────────────────┐
  │ 3. /exec_remote-deploy                       │
  │    bootstrap-vps.sh (Node·tmux·UFW·fail2ban) │
  │    deploy-kit.sh (orchestration_v1 clone)    │
  │    claude login (사용자 토큰 입력)           │
  │    tmux 세션 3개 (claude·worker·main)        │
  └─────────────────┬────────────────────────────┘
                    │ 24/7 작동
                    ▼
  ┌──────────────────────────────────────────────┐
  │ 4. /exec_remote-mobile                       │
  │    Termius 앱 설치 + private key import      │
  │    호스트 등록 + snippet 등록                │
  │    어디서든 SSH → tmux attach -t claude     │
  └──────────────────────────────────────────────┘

언제든:
  /exec_remote-status → 핑·CPU/RAM·heartbeat 한 화면
  /exec_remote-tmux   → 세션 패턴·단축키 cheatsheet
```

## 비용 (예상)

| 항목 | 비용 |
|---|---|
| Oracle Free Tier 4 OCPU/24GB/200GB | **$0/월** |
| Claude API (Sonnet 4.6 + 캐싱 활용) | $3~10/월 (사용량 따라) |
| 도메인 (선택) | $10/년 |
| **합계** | **$3~10/월 + 도메인** |

> AWS EC2 동급 사양 = 월 $50~100. Oracle 무료가 압도적 가성비.

---

## 보안 우선순위 (필수)

1. SSH 키 ED25519 사용 (RSA 2048 비추)
2. 비밀번호 로그인 비활성 (`PasswordAuthentication no`)
3. UFW 22(또는 변경 포트)·80·443 만 허용
4. fail2ban (brute-force 차단)
5. private key 패스프레이즈 권장 (분실 대비)
6. 폰의 Termius 에는 Touch ID/Face ID 보호 활성

---

## 주의사항

- **카드 등록**: Oracle 가입 시 일시 $1 검증 후 환불. 청구되지 않음.
- **Capacity 부족**: ARM 인스턴스 발급 실패 시 → 다른 시간대 재시도 또는 Vultr 폴백.
- **Always Free 자원만 사용**: 실수로 paid shape 만들면 과금. VM.Standard.A1.Flex 의 4 OCPU/24GB 한도 안에서만.
- **인증 우회 금지**: Claude Code 토큰을 git commit 하지 말 것 → `.env` 또는 `docs/ini/`.
