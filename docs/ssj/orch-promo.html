  • · 멀티AI 오케스트레이션
    Claude 설계 → Codex 구현 → Gemini 검증. 각 AI의 강점을 극대화하는 라우팅.
  • · Zero-touch 자동화
    사용자 액션 0개. SessionStart부터 MCP 연결, 워커 관리까지 완전 자동.
  • · 풀스택 시스템 설계
    프론트(HTML/CSS) · 백엔드(Python) · 인프라(스크립트) · AI(프롬프트).
  • · 49개 산업별 공통 레퍼런스
    금융·의료·교육·보안·IoT 등 모든 산업의 공통 도구 정리.
  • · 품질 자동 검증
    빌드→검증→보고 자동 파이프라인. Self-Critique 다중 AI 합의.
  • · 실행 중심 (Bias for Action)
    계획에 머무르지 않고 즉시 구현. 작은 변화를 빠르게 반복.
  • · 도메인 통찰력
    금융·보안·교육·헬스 각 산업의 핵심 워크플로우 이해.

일을 대하는 방식

탐구 → 분석 → 설계 → 실행 → 검증

  • · 1. 탐구 — 문제의 본질·맥락·이해관계자 파악
  • · 2. 분석 — 데이터로 가설 검증, 정량 측정
  • · 3. 설계 — AI와 함께 최적 아키텍처 도출
  • · 4. 실행 — 자동화로 결과를 만든다
  • · 5. 검증 — Self-Critique·다중 AI 합의로 품질 보장

자동화 철학

  • · 사람은 판단만, 반복은 기계에게
  • · 한 번만 하면 끝나는 시스템 (idempotent)
  • · Zero-touch = 사용자 액션 0
  • · 검증 없이 완료 보고 금지
  • · 5단계 자가 점검 (전수·분석·실행·확인·보고)
  • · Hook 으로 100% 강제, 메모리는 보조

협업·소통 원칙

  • · 직접 답 — 회피·딴말 X, 직답 → 부연 → 행동
  • · 전수조사 — 부분 처리 X, 같은 패턴 전 영역 점검
  • · 증거 기반 — "확인 안 됨" 솔직, 추측 단정 X
  • · 회고·학습 — 실패 패턴 기록, 같은 실수 반복 X
  • · 승인 게이트 — 위험 명령 사전 승인 (HITL)

성장 마인드셋

  • · 매일 1% 더 나은 결과 추구
  • · 실패 = 학습 데이터, 회피 X
  • · 도메인 + AI 융합 추구
  • · 글로벌 트렌드 매주 점검
  • · 동료에게 배우고 가르치기
