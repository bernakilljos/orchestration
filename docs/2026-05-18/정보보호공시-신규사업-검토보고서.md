## 2. ISMS-P 와 정보보호공시 — 관계 정리

### 2.1 흔한 오해 정정 (사업부 결정에 영향)

| 오해 | 실제 |
|---|---|
| "ISMS 인증 받으면 공시 자동" | ❌ 별개 의무. ISMS 인증 + 공시 별도 매년 제출 |
| "공시가 ISMS 안에 포함" | ❌ 공시 양식 안에 'ISMS 보유' 한 항목 |
| "CEO 개인 의무" | ❌ 법인 의무. CEO 는 회사 대표 책임만 |
| "ISMS 1.1.1 = 공시" | ❌ 1.1.1 은 ISMS 내부 통제 (CEO 경영진 참여) |

### 2.2 ISMS-P 1.1.1 ↔ 공시 차이

```
[ISMS 1.1.1 - CEO 의무]              [정보보호공시 - 회사 의무]
"CEO 가 정보보호 정책에                "회사가 정보보호 현황을
 승인·참여·보고받음"                    외부에 공시"
↓                                    ↓
ISMS 인증 받기 위한 통제                별도 의무 (정보보호산업법)
↓                                    ↓
인증서 발급 (3년)                      매년 KISA 포털 게시
```

→ **1.1.1 통제는 인증 받기 위한 내부 활동**. 공시는 외부 공개 의무. 별개 차원.

### 2.3 양식 안 ISMS 항목 (공시 5개 영역)

| 영역 | 내용 | ISMS 활용 가능성 |
|---|---|---|
| ① 투자 | 예산·지출액 (재무 정합성 강화) | 회계 원장 — 회계법인 강점 |
| ② 인력 | 전담·겸직 인력 | ISMS 인증 자료 그대로 활용 ⭐ |
| ③ **인증** | **ISMS / ISMS-P / 기타** | **인증서 그대로 인용** ⭐⭐⭐ |
| ④ 활동 | 점검·훈련·교육 | ISMS 증적 자료 그대로 활용 ⭐⭐ |
| ⑤ 부가 | 외주 보안서비스 등 | 일부 |

→ **5개 중 3개 영역이 ISMS 자료 그대로 활용 가능**. 회계법인은 ②·③·④ 약함.

## 3. 경쟁 현황 — 회계법인 빅3 진입 완료

### 3.1 시장 진입 현황

| 회사 | 서비스 | 출시 시점 | 핵심 기능 |
|---|---|---|---|
| **삼정KPMG** | 'AI 기반 스마트 정보보호 공시 자동화 플랫폼' (SaaS 구독) | 2025-05 | AI 키워드 분류 → 회계 원장에서 보안항목 자동 추출, 시간 90% 단축 |
| **삼일PwC** | AI 기반 정보보호 공시 검증 전문 서비스 | 출시중 | 시행령 개정 대응 |
| **EY한영** | Auto Sampling + RPA 맞춤 솔루션 | 출시중 | 회계 정합성 검증 강화 |

### 3.2 회계법인의 공통 강점·약점

| 강점 | 약점 |
|---|---|
| 회계 원장 직접 접근·해석 | **ISMS-P 통제·증적 깊은 이해 부재** |
| 회계 정합성 검증 (사후검증 강화 대응) | **중소·중견 가격대 미진입** (수천만~억 단가) |
| 빅4 브랜드 신뢰 | ISMS 인증 컨설팅 채널 약함 |
| AI / RPA 인프라 | 정보보호 도메인 깊이 부족 |

### 3.3 INFOTRUST (사용자 언급) 추가 조사 필요

블로그 언급 — 공식 사이트 미확인. Phase 0 조사 대상.

## 4. 코어 진입 가능성 분석

### 4.1 5가지 옵션 비교

| # | 서비스 | 회계법인 강점 | 코어 진입 여백 |
|---|---|---|---|
| 1 | 공시 양식 자동 작성 SaaS | 강점 영역 | ❌ 직접 충돌, 늦은 진입 |
| 2 | **ISMS ↔ 공시 통합 SaaS** | **약점 영역** | **⭐⭐⭐ 차별화 핵심** |
| 3 | 사후검증 대응 컨설팅 | 강점 영역 | ❌ 충돌 |
| 4 | **중소·중견 특화 가벼운 SaaS** | **약점 영역** (가격대) | **⭐⭐⭐ 타겟 차별화** |
| 5 | 공시 데이터 외부 활용 분석 | 약점 영역 | ⭐⭐ B2B 데이터 (장기) |

### 4.2 추천 — **옵션 2 + 4 결합**

**"ISMS-P 인증사 전용 공시 자동화 SaaS — 중소·중견 타겟"**

#### 진입 근거

1. **시장 공백 명확**: 2026 개정 후 ISMS 인증 의무사 1,400개 신규 공시 의무화. 회계법인은 상장 대기업 중심
2. **회계법인 약점 정확히 공략**: ISMS-P 통제·증적 자료 깊이 이해 필요
3. **가격대 차별**: 회계법인 수천만~억 → 우리 월 50~100만 / 년 600~1,200만
4. **코어 강점 활용**: ISMS-P 컨설팅 경험 + AI 자동화 결합 가능

## 6. MVP 설계 — 5단계 자동화

### 6.1 핵심 기능 흐름

| 단계 | 입력 | AI/자동화 | 출력 |
|---|---|---|---|
| **1** | ISMS-P 인증서·증적 PDF/Word | OCR + LLM (Claude/Codex) 항목 추출 | 인증·인력·활동 구조화 데이터 |
| **2** | 회계 원장 (전표 CSV/Excel) | AI 키워드 분류 → 정보보호 인건비·투자 자동 분류 | 양식 ① ② 자동 채움 |
| **3** | 1+2 통합 매핑 | KISA 양식 자동 채움 | 공시 양식 초안 (.xlsx/.docx) |
| **4** | 3 초안 검토 | LLM 작성 → 컨설턴트 검토 | 사전점검 보고서 초안 |
| **5** | 4 보고서 | (선택) 양식 download → KISA 포털 사용자 제출 | 제출 완료 + 사후검증 대응 가이드 |

### 6.2 ISMS-P 통제 매핑 (차별화 핵심)

| ISMS-P 통제 영역 | 공시 양식 영역 | 자동 매핑 가능 |
|---|---|---|
| 1.1 관리체계 기반 (CISO 지정·자원할당) | ② 인력, ⑤ 부가 | ⭐⭐⭐ |
| 1.2 위험관리 | ④ 활동 (위험평가) | ⭐⭐ |
| 1.3 관리체계 운영 | ④ 활동 (운영현황) | ⭐⭐ |
| 1.4 관리체계 점검 | ④ 활동 (점검·훈련) | ⭐⭐⭐ |
| 2.x 보호대책 (인증·인력) | ② 인력, ③ 인증 | ⭐⭐⭐ |
| 3.x 개인정보 처리 | ④ 활동 (개인정보) | ⭐⭐ |

→ **회계법인 모르는 영역**. 우리 차별화 점.

### 6.3 기술 스택 후보

| 영역 | 기술 |
|---|---|
| AI 엔진 | Claude Opus 4.7 (분석·매핑) + Codex (양식 자동 작성) + Haiku (검증) |
| OCR | EasyOCR / Tesseract (PDF/Word 증적) |
| 회계 분류 | Python + scikit-learn (키워드 + ML 분류) |
| 양식 | python-docx + openpyxl (KISA 양식 .xlsx) |
| 백엔드 | FastAPI |
| 프론트 | Next.js (SaaS UI) |
| 인프라 | AWS / Azure (보안 인증 필요) |

### B. 용어 정리 (참고)

| 용어 | 설명 |
|---|---|
| **ISMS** | 정보보호 관리체계 (Information Security Management System) |
| **ISMS-P** | ISMS + 개인정보보호 통합 인증 |
| **CISO** | 정보보호최고책임자 |

| **사후검증** | 제출 후 회계·감리 전문가 종합 검토 |
| **KISA** | 한국인터넷진흥원 (Korea Internet & Security Agency) |
