# 산업 ML 이식 답변 형식 룰

> **근거**: 2026-07-01 사용자 지침 — "산업에 쓴 [기술]을 써보자 → [효과]" 형식 반복 요구.
> **이유**: 사용자 = ENFP + ADHD-like. 긴 접목 essay 지루. Breadth + 짧은 제안 원함.

## 절대 룰

**"다른 산업 X 를 [대상 도메인] 에 접목 가능?" 질문 시 → 표 + 한 줄 제안 형식.** 긴 mechanism essay 금지.

**대상 도메인은 dynamic**: 사용자가 지정하는 그것 (RMS·ICM·CCP·EPM·주식·부동산·헬스케어·법률·교육·게임·엔터·플랫폼·모빌리티·기타 모든 도메인). 하드코딩 X.

## 발동 트리거

- "X 산업 [도메인 Y] 접목 가능?"
- "다른 산업 기술 뭐 있어?"
- "AI 기술 뭐가 있어 [도메인 Y] 에?"
- "너가 생각하는 추가할 기술 뭐?"
- 기술 이름 여러 개 나열 시 → 각각 O/X

##  원하는 답변 형식

### 1. 한 줄 답 (yes/no)
> "YES · 접목 가능" 또는 "부분적으로 가능"

### 2. O/X 표
| [원 산업] 기술 | [대상 도메인] |
|---|---|
| 기술 A (짧은 설명) | O |
| 기술 B | X (이유) |

### 3. 5살 톤 · 비유
- 각 기술마다 1줄 설명 (비유 우선)
- "[원 산업]에 쓴 [기술]을 써보자 → [효과]" 형식

### 4. 여러 산업 breadth (사용자 특정 안 하면)
- 한 산업만 X, 여러 산업 함께
- 사용자가 특정 지정 시만 그 산업 집중

### 5. spark 열어둠
- 마지막 "spark 되는 것 짚어주세요"
- 다음 산업·기술 자유 지정 가능하게

##  금지 형식

1. **긴 mechanism essay** — "어떻게 옮기면 이렇게 됨" 스텝 나열
2. **접목 5-6 문장 설명** — 각 기술마다 architecture 상세
3. **여러 페이지 시나리오** — 3개 시나리오 → 5-6개 결과
4. **결정 강요** — "A/B/C 중 골라주세요" 3번 반복
5. **딴 주제 전환** — "근데 이건 어때요?" 우회
6. **특정 도메인 하드코딩** — RMS 만 가정 X. 사용자 관심 도메인 유연 매핑

## 예시

### 좋은 예시 (대상 도메인 = 아무거나)

**질문**: "자율주행 기술 → [사용자 지정 도메인] 접목?"

```text
자율주행 기술 → [도메인] O/X:

| 자율주행 기술 | [도메인] |
|---|---|
| Edge Case Detection | O |
| GAN Synthetic Data | O |
| Sensor Fusion | O |
| Facial Expression AI | O |
| LiDAR (3D 스캔) | 도메인에 따라 다름 |
| HD Map | 도메인에 따라 다름 |
```

도메인 예시:
- RMS → 리스크 감지 관점
- 헬스케어 → 환자 모니터링
- 교육 → 학습 이상 감지
- 게임 → 부정 사용자 감지
- 법률 → 계약 리스크 자동 검토
- 부동산 → 시세 이상 감지
- 커머스 → 사기 결제 감지

### 나쁜 예시 (하지 말 것)

```text
자율주행에서 어떻게 작동:
1. 정상 주행 시나리오 수백만 학습
2. Edge Case = 훈련 데이터 밖 상황
3. GAN/Diffusion 으로 rare 시나리오 자동 생성

RMS 옮기면:
문제: 실제 부정 데이터 = 연 몇 건
해결: GAN 으로 부정 시나리오 대량 합성
...5-6 문장 더...
```

→ 사용자 지루 유발. 이런 essay X.

## Why

**Reason**: 사용자 (ENFP-ADHD) 는 breadth + 짧은 제안 선호. 여러 산업 한 번에 훑고 spark 오는 것만 depth. 매 답변마다 5-6 시나리오 essay = 지루·짜증. 또한 사용자 관심 도메인은 유동적 (RMS·ICM·주식·부동산·헬스케어 등) — 특정 도메인 하드코딩 시 다른 도메인 질문에 대응 못 함.

**How to apply**:
1. 산업 접목 질문 → 즉시 표 형식
2. 각 라인 = "산업에 쓴 기술 → [사용자 지정 도메인] 효과" 한 줄
3. O/X 명확히
4. 여러 산업 함께 (사용자 지정 시만 특정)
5. 사용자 지정 도메인 유연 매핑 (RMS·ICM·주식·부동산·헬스케어·법률·교육·기타)
6. 마지막 spark 요청
