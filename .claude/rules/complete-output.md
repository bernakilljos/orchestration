# 완전본 원칙 (Complete Output) — 헌장 D21

> **근거**: 2026-10-14 사용자 지적 — "전체 문구 달라고 했는데 쪼개고 줄이고 되묻는다 · 내가 예를 든 거지, 하나만 고치면 10000개면 어떻게 하래".
> 사례 하나(서버 점검 명령)를 고치거나 감지 키워드를 늘리는 건 해결이 아니다. **원칙**이 없어서 세션마다 마음대로 재구성했다.
> 이 파일은 `.claude/rules/` 라 **모든 세션이 시작할 때 자동으로 읽는다** — 키워드 감지 없이도 항상 적용된다.

## 절대 룰

**사용자가 달라고 한 것은 무엇이든 (명령·SQL·DB 문구·설정·코드·문서·메시지·표) 완전본을, 사용자가 준 형식 그대로, 한 번에 준다.**

| # | 지킬 것 | 하지 말 것 |
|---|---|---|
| 1 | **전부** — 요청 범위 전체 (예시로 하나를 들어도 같은 종류 전부) | 일부만 · `...생략` · "나머지도 같은 식" |
| 2 | **받은 형식 그대로** — 헤더·섹션 번호·순서·이름 유지 | 대상마다 다르게 재설계 · 번호 줄이기 · 내 방식으로 재구성 |
| 3 | **한 블록** — 한 번에 복사 가능 (여러 대상이면 같은 블록 안에 이어서) | 대상별로 쪼개고 제목 붙이기 |
| 4 | **바로** — 결정된 범위는 즉시 | "원하시면 ~ 드립니다" 되묻기 (헌장 D6·D8) |
| 5 | **고친 점은 뒤에 짧게** — 실제 결함만 고치고 블록 뒤 3줄 이내 | 설명을 앞에 길게 · 결함 아닌 취향 변경 |
| 6 | **문구만** | 도구 실행 흔적(heredoc·EOF·메모리 저장 명령)을 답변에 섞기 |

해당 항목이 그 대상에 의미가 없으면 **항목은 남기고** "(해당 없음)" 으로 채운다 — 구조를 바꾸지 않는다.

## 일반화 원칙 (같은 종류 결함 전체)

| 지적 | 잘못된 대응 | 올바른 대응 |
|---|---|---|
| "a 페이지 안 맞아" (100페이지 중) | a 만 수정 | 같은 원인을 가진 100페이지 전부 찾아 수정 · "100개 중 100개" 보고 |
| "이 쿼리 틀렸어" | 그 쿼리 1개 | 같은 패턴 쿼리 전부 |
| "메일 문구 이상해" | 그 문장 1개 | 같은 문구 쓰는 메일·템플릿 전부 |
| "전체 문구 줘" (서버·DB·메일 무엇이든) | 일부·재구성 | 받은 형식 그대로 전부 |

2026-10-14 원인 실측 (재발 방지): ① 원칙이 kit CLAUDE.md 에만 있고 대상 폴더 CLAUDE.md(대상 고유본)엔 0줄 → 이 룰 파일로 전파 ② 감정 hook 이 "사용자 결정 받고 실행" 을 주입해 되묻기를 지시 → 삭제 ③ "a 안 맞아" 류 지적엔 아무 원칙도 안 붙음 → 「결함 지적 · 같은 종류 전체」 주입 ④ 열린 세션은 새 룰을 /clear 전까지 못 읽음.

사용자가 **예를 들어** 지적하면 그 예 하나가 아니라 **같은 종류 전체**를 고친다.
- 고치기 전에 묻는다: "이 결함이 다른 대상·다른 표현·다른 파일에도 있나?" → 전수 확인 후 한 번에.
- 키워드·사례를 하나씩 추가하는 방식은 보조일 뿐 해결이 아니다 — 원칙(이 룰)·구조(공통 함수·게이트)로 막는다.

## 작업 미루기 금지 (compact·clear) — 2026-10-14

**남은 작업이 있으면 사용자에게 "compact 해 주세요 / clear 해 주세요" 를 요청하지 않는다. 그대로 계속한다.**
- 근거(실측): Claude 는 `/compact`·`/clear` 를 실행할 수 없다(사용자 명령). 사용자가 직접 하면 **다음 메시지까지 작업이 멈춘다.**
  반면 97% 자동 compact 는 작업 도중에 일어나 **스스로 이어 간다**.
- 원인이던 지시 2개 제거: `auto-compact-check.sh` 의 «다음 턴 첫 동작으로 /compact 자체 실행» · `inject-compact-reminder` 의 «작업 경계에서 /clear 권장».
- "이어서 할 일: …" 을 남기고 끝내지 않는다 — 그 일을 지금 한다. 작업이 **다 끝났을 때만** "끝났으니 /clear 해도 됩니다" 한 줄.
