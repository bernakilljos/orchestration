# 문구 요청 룰 (Copy-Text Request)

> **근거**: 2026-10-14 사용자 지적 — "전체 문구 달라고 했는데 왜 쉘스크립트를 주는 거야 · 핑퐁해 · 내 말 무시".
> A1.RMS-UPG 세션이 3서버(#api·#batch·#fe) 점검 명령 템플릿을 받고 ① 서버별로 쪼개 제목을 붙이고 ② FE 섹션을 [1]~[5]로 줄이고
> ③ "원하시면 맞춰 드린다"고 되묻고 ④ 메모리 저장 heredoc(EOF) 를 답변에 섞었다 → 사용자가 3번 다시 요청.

## 절대 룰

**"문구 줘 / 전체 문구 / 복사할 수 있게 / 복붙" = 사용자가 준 형식 그대로, 요청 범위 전체를, 코드블록 1개로 바로 준다.**

| # | 지킬 것 | 하지 말 것 |
|---|---|---|
| 1 | 사용자 템플릿의 헤더(`#api` 등)·섹션 번호·순서 유지 | 대상마다 다른 구성으로 재설계 · 섹션 번호 줄이기 |
| 2 | 한 블록 = 한 번에 복사 (여러 대상이면 같은 블록 안에 이어서) | 대상별로 블록을 쪼개고 제목 붙이기 |
| 3 | 요청 범위 전체 (일부만 물어도 "전체" 면 전부) | "원하시면 ~ 드립니다" 되묻기 |
| 4 | 실제 결함만 고치고, 고친 점은 블록 **뒤** 3줄 이내 | 설명을 블록 앞에 길게 · 결함 아닌 취향 변경 |
| 5 | 답변에는 문구만 | 도구 실행 흔적(heredoc·EOF·메모리 저장 명령) 노출 |

해당 섹션이 그 대상에 의미가 없으면 (예: nginx 서버의 JVM) **섹션은 남기고** "(해당 없음)" 을 출력하게 한다 — 번호 체계를 바꾸지 않는다.
