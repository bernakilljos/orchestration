# /design_excel — Excel 생성 허브

## 포함 커맨드
- `/make` — Excel 파일 생성 (**기본 액션, design_word와 이름 중복**)
- `/status` — 생성 상태 확인

## 참고
`/make`, `/status`는 design_word와 이름이 같음. 현재 로드된 것이 어느 플러그인인지는 파일 내용으로 확인.

## 기본 실행
`/make` — 표·차트 포함 .xlsx 생성.
