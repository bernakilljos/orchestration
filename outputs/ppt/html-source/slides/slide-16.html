플러그인 시스템

.claude-plugin/ + plugin.json

플러그인 = commands/skills/hooks/agents를 묶은 배포 단위. plugin.json 에 이름·버전·의존성. marketplace.json 으로 여러 플러그인 번들 공유. 설치: claude plugin install 또는 git clone.

필수 필드: name, display, version, status (stable/experimental/spec-only), commands.

선택 필드: skills, agents, hooks, dependencies.plugins (의존성), entry_points.default_command.

◆ 플러그인 장점

  • 공유·재사용
  • 버전 관리
  • 팀 표준 배포
  • 공개 마켓플레이스
재사용 가능한
단위로 번들링
