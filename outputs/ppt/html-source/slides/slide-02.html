Claude Code

터미널에 들어온 AI 페어 프로그래머 · 프로젝트 폴더 = 작업공간

Claude Code 는 터미널에서 돌아가는 AI 에이전트. 파일 읽고·쓰고·실행·git·MCP. 웹 UI 가 아니라 프로젝트 폴더 자체가 작업 공간이다. 새 프로젝트에서 /init 실행하면 자동으로 .claude/ 와 CLAUDE.md 생성. 

$ cd my-project
$ claude
Welcome to Claude Code. Ready to help.
> /init
Scanning codebase...
Detected: Next.js 15, TypeScript, Tailwind
Generating CLAUDE.md draft...
// Done. Review docs/CLAUDE.md
> _

◆ 핵심 특징

  • 터미널 CLI 기반
  • 폴더 = 작업공간
  • .claude/ 에 모든 맥락
  • /init 자동 세팅
  • MCP·훅·플러그인
  • Multi-AI 오케스트레이션

◆ 시작

  • claude --help
  • /init — 자동 세팅
  • CLAUDE.md 큐레이션
참조: docs.claude.com/claude-code
