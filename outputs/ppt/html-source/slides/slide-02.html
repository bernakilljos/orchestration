Claude Code

터미널에 들어온 AI 페어 프로그래머

Claude Code는 터미널에서 돌아가는 AI 에이전트. 파일을 읽고·쓰고·실행하고·git을 조작하고·MCP 서버를 호출한다. 핵심은 .claude/ 폴더에 모든 규칙·명령·훅·스킬이 담긴다는 것.

새 프로젝트에서 /init을 실행하면 Claude가 코드베이스를 스캔해서 .claude/ 와 CLAUDE.md를 자동 생성한다.
