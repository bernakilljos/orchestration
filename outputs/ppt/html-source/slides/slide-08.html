settings.json

권한 · 훅 · MCP · 플러그인

settings.json 은 권한 관리 (allow/deny/ask 배열), 훅 정의 (이벤트 → 명령), MCP 서버 활성화, 플러그인 설정 을 한 곳에서 처리. 팀 공유 (git commit).

defaultMode 로 전체 권한 수준 결정: 'default' (매번 물음), 'acceptEdits' (에디터 명령 자동 승인), 'plan' (계획만), 'bypassPermissions' (관리자 모드).

env 섹션 으로 환경변수 정의. enabledMcpjsonServers, enabledPlugins 로 활성화할 MCP/플러그인 목록 관리.

{
  "permissions": {
    "allow": ["Bash(npm:*)", "Edit"],
    "deny": ["Bash(rm -rf *)"],
    "defaultMode": "acceptEdits"
  },
  "hooks": {
    "PostToolUse": [{
      "matcher": "Edit|Write",
      "hooks": [{
        "type": "command",
        "command": "prettier --write $FILE"
      }]
    }]
  },
  "enabledMcpjsonServers": ["github", "filesystem"]
}
