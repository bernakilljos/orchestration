settings.json

권한 · 훅 · MCP · 플러그인 · 한 곳에서 · 팀 공유 (git commit)

defaultMode 로 전체 권한 수준을 정한다: default (매번 물음), acceptEdits (에디터 명령 자동 승인), plan (계획만), bypassPermissions (관리자). 

{
  "permissions": {
    "allow": ["Bash(npm:*)", "Edit"],
    "deny": ["Bash(rm -rf *)"],
    "defaultMode": "acceptEdits"
  },
  "hooks": {
    "PostToolUse": [{
      "matcher": "Edit|Write",
      "hooks": [{"type": "command",
                 "command": "prettier --write $FILE"}]
    }]
  },
  "enabledMcpjsonServers": ["github"]
}
