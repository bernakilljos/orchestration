◆ 권한 룰 문법

  • Bash(npm *) 와일드카드
  • Edit(.claude) 경로 한정
  • Read 도구 전체
  • Write(/etc/*) 차단/물음

◆ 우선순위

  • deny > ask > allow
  • local > project > user
  • 구체 룰 > 와일드카드
