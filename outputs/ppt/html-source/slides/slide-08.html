4.7의 4대 기능

1M 토큰과 그것을 가능하게 하는 기술들

1️⃣
1M Token Window
200K에서 1M으로 5배 확대. 전체 프로젝트 컨텍스트를 한 번에 로드 가능. 코드 리뷰, 아키텍처 결정이 이제 한 번의 질문으로 끝난다.
💾
Prompt Caching
5분 이내 같은 컨텍스트 재사용 시 90% 비용 절감. 예: 파일 600개(1M 토큰)를 캐시하면 재사용 때 $1.50 → $0.15. 반복 작업 최적화.
🧠
Extended Thinking
내부 추론 프로세스 노출. 복잡한 아키텍처 결정을 8단계로 분해 가능. 설계 검증, 버그 원인 분석, 리팩토링 계획 수립에 강력.
💰
$15 / $75
input $15/M 토큰, output $75/M 토큰. Caching 포함 시 실효 비용은 더 낮음. 이전 4.6대 비 가성비 극적 개선.

이 네 가지는 독립적이 아니라 상호 보강된다. 1M 토큰이 있어야 Caching이 의미 있고, Caching이 있어야 비용이 경제성이 생긴다. Extended Thinking은 복잡도를 제어한다.
