🔴 Before (4.6)

  • • 200K 토큰 제한
  • • 매번 전체 컨텍스트
  • • API 호출 때마다 비용
  • • 간단한 분석만 가능

🟢 After (4.7)

  • • 1M 토큰 윈도우
  • • Prompt Caching
  • • Extended Thinking
  • • 5배 저렴

1M 토큰은 무엇을 의미하는가? 전체 프로젝트(코드, 문서, 테스트, 예시 25개)를 한 번에 올릴 수 있다. 이전엔 불가능했다.

◆ 4가지 핵심 변화

  • 1M 토큰 윈도우
  • Prompt Caching (5분 재사용)
