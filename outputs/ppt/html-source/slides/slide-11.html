SQLite 기반 로컬 데이터베이스 orca.db. 매초 수집한 지표들을 저장한다. 필요한 것을 쿼리하면 된다. 의존성 없이, API 초과 비용 없이.

tasks
ID, user_id, status, created_at, updated_at, result
workers
worker_id, model, status, tasks_done, uptime_sec
metrics
timestamp, metric_name, value, worker_id
cache_hits
timestamp, context_hash, hits, misses, ratio
costs
task_id, model, input_tokens, output_tokens, cost_usd
errors
timestamp, worker_id, error_type, message, retry_count
latencies
timestamp, p50, p95, p99, max_ms
queue_stats
timestamp, queue_depth, avg_wait_sec, pending_tasks
