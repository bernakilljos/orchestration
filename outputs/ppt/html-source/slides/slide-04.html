exec_orch 엔진

3개 AI를 한 번에 지휘하는 오케스트라

멀티AI 협업의 핵심은 올바른 순간에 올바른 AI를 부른다는 것이다. exec_orch는 작업의 특성(규모, 유형, 복잡도)을 읽어 Claude는 설계를, Codex는 구현을, Gemini는 검증을 하도록 라우팅한다.

🧠
Claude
설계 · 판단 · 승인 · 문서 작성 · 아티팩트 생성
⚙️
Codex
500줄+ 코드 1차 구현 · 병렬 실행 · 속도 최적화
🔍
Gemini
초장문 검증 · 보안·성능·품질 체크 · 500k 토큰

라우팅 로직은 route_dispatch.md 스킬에 명시되어 있다. 작업 규모(줄 수), 복잡도(의존성), 시간(deadline)을 종합해 판단한다.

◆ 라우팅 기준

  • 코드 <200줄: Claude
  • 코드 200~500줄: Codex 1st
  • 코드 >500줄: 병렬 Codex
  • 검증 필요: Gemini
  • 설계 판단: Claude 최종
