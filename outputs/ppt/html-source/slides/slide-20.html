3 스코프 · 충돌 시

Folder > Project > Global · 가까운 것이 이긴다

◆ 실제 충돌 시나리오 · 들여쓰기

Global ~/.claude/CLAUDE.md tab 4 space
Project ./CLAUDE.md tab 2 space
Folder ★ ./src/CLAUDE.md tab 8 space
→ src/ 안에서는 8 space 적용. 바깥은 2 space.

◆ 우선순위

  1. Folder (모듈 국소)
  2. Project (리포 공통)
  3. Global (개인 선호)
규칙 — 같은 키가 여러 레벨에 정의되면 가장 가까운 것 만 적용. 멀리 있는 규칙은 무시.

◆ 활용

  1. 개인 선호 → Global
  2. 팀 컨벤션 → Project
  3. 특수 모듈 → Folder
