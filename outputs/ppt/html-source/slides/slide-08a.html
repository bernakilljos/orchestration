훅 · MCP · 플러그인

한 파일에서 자동화 + 외부 도구 + 확장을 모두 제어

{
  "hooks": {
    "PostToolUse": [{
      "matcher": "Edit|Write",
      "hooks": [{
        "type": "command",
        "command": "prettier --write $FILE"
      }]
    }]
  },
  "enabledMcpjsonServers": ["github", "playwright"],
  "enabledPlugins": {
    "code-review@claude-plugins-official": true
  },
  "env": { "DEBUG": "true" }
}
핵심: 메모리·프롬프트는 70~80% 지킴, hooks 는 100% 강제 — 자동화에 절대적
