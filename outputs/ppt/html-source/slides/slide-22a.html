Tips & Tricks · 6 가지 실전 노하우

현장 실사용에서 검증된 시간 절약 패턴들

TIP 01
@ 로 파일 직접 참조
"이 파일 읽어줘" 대신 @src/auth.ts 입력 → 자동 컨텍스트 로드. Read 도구 호출 안 거치고 바로 처리.
TIP 02
! 접두로 Bash 즉시 실행
슬래시 명령 본문에 !`git log -5` 식으로 작성하면 Claude 가 결과를 그대로 컨텍스트로 사용.
TIP 03
# 로 메모리 즉시 추가
대화 중 # 로 시작하면 해당 줄을 CLAUDE.md 또는 메모리에 영구 저장. 반복 지시 제거.
TIP 04
/clear & /compact 활용
긴 대화 후 /compact 로 핵심만 요약 보존, /clear 로 컨텍스트 완전 초기화. 토큰 80% 절약.
TIP 05
Plan Mode (Shift+Tab)
실행 전 계획만 보기. 큰 변경 시 안전장치. defaultMode: "plan" 으로 영구 설정 가능.
TIP 06
Sub-Agent 병렬 실행
검증·리서치는 Sub-Agent 에 위임 (Sonnet/Haiku 사용 가능). 토큰 격리 + 비용 절감 + 병렬 처리.
