# my-shop · Next.js 15 SaaS

> 목적: 다AI 협업이 이해할 수 있는 단일 컨텍스트

## 1. WHAT
- Stack: Next.js 15 · TypeScript · Tailwind
- DB: PostgreSQL · Prisma
- Test: Vitest · Playwright
- 배포: Vercel + Preview Branch

## 2. WHY (원칙)
- 컴포넌트: PascalCase, 변수: camelCase
- 폼: react-hook-form + zod 만 사용
- API 응답: {data, error} 통일
- // 금지: any 타입, console.log, 하드코딩 키

## 3. HOW
- Build: npm run build
- Test: npm test
- Lint: eslint --fix
- Commit: feat/fix/docs/refactor
- Deploy: PR 머지 시 자동 배포

컨텍스트 제공
기술 스택·핵심 의존성·환경 변수. AI 가 코드를 읽기 전에 알아야 할 사실들.

PART 2 · WHY

원칙 + 안티패턴
코드 스타일·네이밍·금지 패턴. // 금지: 라벨로 하지 말아야 할 것 명시.

PART 3 · HOW

실행 명령
