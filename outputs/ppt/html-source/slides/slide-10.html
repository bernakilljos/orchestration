# Auto PR Review

1. git diff main..HEAD 변경점 추출
2. 보안·성능·테스트 체크
3. 결과를 PR 코멘트로 작성

◆ SKILL 원칙

  • kebab-case 폴더명
  • SKILL.md 정확히
  • description ≤ 1024자
  • 본문 ≤ 5000단어
  • 트리거 문구 구체

◆ 점진 공개 3단계

  • 1. frontmatter (항상)
  • 2. 본문 (관련 시)
  • 3. assets/scripts (필요시)
