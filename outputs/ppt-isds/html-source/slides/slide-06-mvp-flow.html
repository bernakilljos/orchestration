05 · MVP · 자동화 동작 + 개발 범위
어떻게 동작하는가 / 무엇을 개발할 것인가

4단계 자동화. 개발 범위 명확.

정보보호 관련 전표 / 인건비 / 외주 자동 추출 = AI 키워드 분류 + 계정과목 매핑. ISMS 인증서 업로드 = 항목 추출 (점검 X).

1
정보보호 회계 항목 자동 추출
INPUT · MicroICM 회계 데이터 (직접 연동)
① 계정과목 매핑 — 정보보호 관련 계정 사전 정의 (보안솔루션·외주보안·교육 등 30~50개).
② AI 키워드 분류 — 전표 적요 LLM 분석 (예: "ESM 라이센스 갱신" → 영역 ① 투자).
③ 부서·직군 자동 분류 — 인건비 = 정보보호 부서·직군 (CISO·보안팀) 자동 식별.
KPMG 못 함: 회계 원장을 외부에서 받아 분류. 우리: MicroICM 안 데이터 직접 접근 — 매년 자동·실시간 갱신.
→ 영역 ① 투자 + ② 인력 자동
2
ISMS 인증서 업로드 (1회만)
INPUT · PDF/Word 인증서 + 점검 결과서
한계 명시: 인증서·결과서에서 항목 추출만. ISMS 점검 자체 수행 X.
EasyOCR + Claude → 인증명·범위·유효기간·점검일·교육 활동 자동 추출. 매년 자동 갱신 (인증서 1회 업로드).
→ 영역 ③ 인증 + ④ 활동 자동
3
KISA 양식 자동 채움 + 회계 정합성 검증
INPUT · 1 + 2 통합 데이터
KISA 표준 양식 5 영역 자동 생성 (.xlsx + .docx).
Cen's TRM 노하우 적용 — 회계 정합성 자동 검증 (사후검증 통과 목적).
→ 양식 초안 + 검증 보고서
4
사전점검 자료 생성 (점검은 외부)
INPUT · 3 양식 초안
한계 명시: 사전점검 자체 X. 사전점검 신청 자료 자동 생성.
점검은 KISA + 외부 ISMS 컨설팅사 (파트너십). 사전점검 통과 = 사후검증 면제.
→ KISA 사전점검 신청 (+200만 옵션)
