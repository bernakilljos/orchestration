팀 도입 시 가장 많이 받는 질문들

Q.토큰 안 넣고 설치했는데 나중에 추가 가능?
A. 가능. docs/ini/github.ini 의 GITHUB_PAT= 에 토큰 붙여넣기 → 다음 명령부터 자동 인식. 또는 setx GITHUB_PERSONAL_ACCESS_TOKEN "ghp_..." 환경변수로.
Q.본판 (orchestration_v1) 도 같이 받아야 함?
A. 아니요. TEAM zip 만으로 모든 기능 동작. 본판은 메인테이너 working repo (sync 원본). 팀 사용엔 TEAM ✓ . 본판이 필요한 경우 → 플러그인 신규 작성/수정 시.
Q.기존 Claude Code 와 충돌?
A. 충돌 없음. setup 이 npm 설치된 구버전 자동 제거 + 새 버전 설치. 기존 ~/.claude/ 의 settings.json 은 보존.
Q.3개 AI (Claude+Codex+Gemini) 다 필요?
A. 아니요. 모드 선택 — Full / Codex 단독 / Gemini 단독. setup.bat codex C:\path 식 호출. API 키 없는 모델 자동 SKIP. 팀 표준은 Full 권장 (Claude 설계 + Codex 구현 + Haiku 검증).
Q.업데이트는 어떻게?
A. 새 TEAM zip 받아 같은 폴더에 풀기 (덮어쓰기). 사용자 데이터 (state DB · CLAUDE.md · outputs) 는 보존됨. 또는 update-remote.bat 스크립트.
Q.팀원마다 같은 PAT 써도 됨?
A. 비추천. 각자 발급 권장 (감사 추적 + 권한 분리 + 회수 가능). 공용 봇 PAT 는 CI/CD 한정. 사람 작업은 개인 PAT — GitHub → Settings → Developer settings → PAT (classic) 발급.
