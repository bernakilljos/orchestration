어디에 어떻게 배포할까

개인 PC · 클라우드 VPS · 팀 공유 — 3 가지 옵션 + 권장 시나리오

기본 = 본인 Windows PC. 클라우드는 24h 가동 필요할 때.
대부분 로컬 PC 면 충분. 자동화 작업 (잠자는 동안 24시간 가동) 또는 모바일 접속이 필요하면 클라우드 VPS. 팀이 같은 도구 쓰려면 팀 zip 공유 → 각자 setup.bat.
옵션 1
로컬 PC · Windows
평소 작업용 · 가장 빠른 시작 · 별도 비용 없음
  • setup.exe 더블클릭 → 5분
  • 경로: %USERPROFILE%\pjt
  • Windows 10/11 · RAM 8GB+
  • 장점: 즉시 사용 · 시크릿 본인 PC 안
  • 단점: PC 끄면 작업 정지
$0
옵션 2
클라우드 VPS · Linux
PC 꺼져도 24h 가동 · 모바일 원격 접속 · 자동화 강력
  • Oracle Free 4 OCPU · 24GB · 무료
  • Vultr · Lightsail $3~5/월 (대안)
  • SSH 키 한 번 + Termius 폰 앱
  • 장점: 24h 가동 · 어디서든 접속
  • 단점: 가입·SSH 셋업 1시간
$0~5/월
옵션 3
팀 공유
여러 명이 같은 도구 사용 · 인프라 공유 · 시크릿 분리
  • 각 멤버: setup.exe 본인 PC
  • 본인 PAT/API 키만 입력 (자동 분리)
  • 같은 26 플러그인 + 25 슬래시
  • 장점: 일관성 · 5분 onboarding
  • 단점: Maintainer 1명 필요
멤버당 $0
▸ 우리 팀 권장 = 옵션 1 + 옵션 3
