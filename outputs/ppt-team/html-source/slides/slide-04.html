첫 명령 — 단 3 단계

설치 끝났으면 이거 한 번만 — Claude 가 모든 규칙 숙지하고 즉시 작업 가능

▸ 설치 후 가장 먼저 할 일
"setup 했으니 CLAUDE.md 읽고 반영해줘"
이 한 줄이면 Claude 가 프로젝트 규칙·역할 분담·금지 사항·핵심 경로를 모두 숙지. 이후 모든 작업이 규칙대로 자동 작동.
1
setup.exe 실행
관리자 권한으로 더블클릭. 14 단계 모듈 자동 실행 — Defender 예외, Claude Code 설치, 글로벌 명령어, 플러그인 모두 자동.
setup.exe → 다음·다음·완료
2
Claude 시작
설치 폴더에서 터미널 열고 claude 입력. 첫 인증 후 모든 도구 즉시 사용 가능.
cd %USERPROFILE%\pjt claude
3
규칙 반영 명령
Claude 한테 한 줄. 모든 규칙 자동 숙지 — 다음부터 묻지 말 것까지 다 안다.
setup 했으니 CLAUDE.md 읽고 반영해줘
