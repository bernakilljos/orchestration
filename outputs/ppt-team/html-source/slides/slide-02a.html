왜 team 폴더를 만들었나

본판은 메인테이너 작업장 · team 은 팀 멤버 onboarding 폴더 — 시크릿·로컬 상태 분리 + 인프라 동기화

▸ 한 줄 요약
팀이 같은 인프라 쓰지만
시크릿은 분리한다
orchestration_v1 (본판) = 메인테이너 작업장.
orchestration_v1_team = 팀 멤버 폴더 — 같은 plugins/scripts/CLAUDE.md 받지만, docs/ini/PAT · .env · .claude/state/ 같은 개인 자료는 자동 제외.
"한 사람이 만든 것을
여러 명이 쓸 때, 시크릿은
각자 가져야 한다."
▸ 분리 원칙 · /sync-team 설계 의도
시크릿 보호
PAT · API 키 · 토큰 이 본판에 있어도 팀에는 자동 제외. 각 멤버가 자기 토큰만 입력 → 권한 분리 + 사고 차단.
5분 onboarding
신규 멤버는 setup.exe 실행 + PAT 입력 한 번으로 끝. 본판의 26개 플러그인·skill·스크립트 모두 그대로 받음.
변경 자동 전파
본판 갱신 → /sync-team 한 번 → 팀 전체에 인프라만 동기화. 각자 작업물·시크릿은 안 건드림.
