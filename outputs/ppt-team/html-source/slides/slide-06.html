토큰 입력 · 두 가지 흐름

토큰 있을 때 / 없을 때 — 어느 경우에도 설치 자체는 성공

토큰 입력 시
FULL — 자동 GitHub 연동
  Token (없으면 Enter): ghp_xxxxx...
  [OK] Token 저장 (User 환경변수)

  Creating GitHub repo: my-project...
  [OK] https://github.com/.../my-project.git
  [OK] git remote add origin
  [OK] Initial commit done

◆ 효과

  • GitHub 저장소 자동 생성
  • remote origin 연결
  • Initial commit + push 가능
  • github MCP 토큰 자동 사용
Enter 만 (SKIP)
LITE — 로컬 git 만, 설치 진행
  Token (없으면 Enter): [Enter]
  [SKIP] GitHub 저장소 생성 단계
         — 토큰 미입력
  [OK] git init done (원격 없음)

  # 나중에 추가하려면:
  # 1. github.ini 에 GITHUB_PAT= 입력
  # 2. setx 환경변수 설정

◆ 효과

  • 로컬 git 만 init (remote 없음)
  • GitHub 저장소 생성 X
  • 나머지 모든 모듈은 정상 진행
  • 나중에 토큰 추가 가능
나중에 추가: docs/ini/github.ini 의 GITHUB_PAT= 에 토큰 붙여넣기 → 다음 setup·install 부터 자동 사용
PAT 발급: https://github.com/settings/tokens · scope: repo 권한 필요
