팀 운영 보안 체크리스트

시크릿 분리 + 토큰 관리 + 동기화 보안 — 모든 멤버가 지킬 것 (체크리스트)

⚠ 절대 금지 (DO NOT)
✗git add 시 docs/ini/ · .env 포함 금지 — gitignore 자동 차단됨
✗PAT (ghp_...) 또는 API 키를 코드 주석에 남기지 마세요
✗다른 멤버 토큰을 폰·이메일·카톡으로 전달 금지 — 본인이 직접 발급
✗--no-verify · --no-gpg-sign 절대 사용 금지 (CLAUDE.md § 7)
✗.claude/state/orca.db 공유 금지 — 본인 작업·비용 정보 포함
✗팀 폴더의 plugins/ 직접 편집 금지 — 본판에 PR 제출
✓ 반드시 (DO)
✓본인 PAT 은 setup.exe 마법사 안에서 입력 → ini 자동 생성
✓의심 스러운 토큰 노출 시 즉시 GitHub Settings → Tokens → Revoke
✓주 1회 /sync-team 으로 본판 변경 받기
✓git status 전 항상 .env · ini 누설 확인
✓Telegram bot token 분실 시 @BotFather → /revoke
✓Claude Code 인증 만료 시 claude login 재실행
✓코드 변경은 본판에 PR — 직접 commit 금지 (Maintainer 만)
✓2주마다 token-stats 로 비용 점검
