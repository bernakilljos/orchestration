BEST PRACTICES 17 / 18

팀 도입 운영 팁

현장에서 안 무너지는 5 가지 해야할 것 + 5 가지 하지마라

✓ DO — 이렇게 해라
CLAUDE.md 먼저 작성
/init 으로 초안 → 팀 컨벤션 추가. 플러그인보다 메모리가 우선.
필요한 MCP 만 설치
전체 plug_all 보다 카테고리별 plug_dev 식으로. 토큰 절약.
hooks 로 자동화 강제
메모리는 70-80% 지킴, hooks 는 100%. 포맷·검증·로그는 hooks 에.
Sub-Agent 병렬 활용
검증·리서치는 Haiku/Sonnet Sub-Agent. 토큰 격리 + 비용 절감.
월 1회 sync 점검
sync-plugins.sh --check 으로 drift·orphan 검사.
예산 상한 + watchdog 항시
route.py --limit 50 일일 한도 + watchdog-start.bat 로 워커 자동 부활.
✗ DON'T — 절대 하지마
.claude/ 직접 편집
자동 sync 결과물. 편집은 plugins/ 원본에서. .claude/ 편집은 sync 가 덮어씀.
비밀 하드코딩
API 키·토큰은 .env 또는 환경변수. .gitignore 필수.
메모리만 의존
"매번 X 해줘" 반복 금지. # 로 메모리 추가 또는 hooks 로 자동화.
Sub-Agent "PASS" 무조건 신뢰
위임 검증은 거짓말 가능. 메인 Claude 가 직접 결과 OCR/Read 로 확인.
전체 plug_all 무조건 실행
설치 시간 + npm 토큰 낭비. 필요한 카테고리만 (plug_dev · plug_data).
빈 task 를 done/ 이동 (위장 완료)
절대 금지 — 워커가 결과 없이 종료 시 main 에서 재발견 + 비용 폭주.
