PLUGIN STRUCTURE 08 / 15

플러그인 표준 구조

SoT 원칙 — plugins/ 가 원본 · .claude/ 는 sync 결과

plugins/<name>/
├── plugin.json           # 필수 스키마 v1.2
├── README.md             # 사용법·예시
├── commands/             # /slash 명령
│   └── *.md
├── skills/               # 자동 활성 스킬
│   └── *.md
├── agents/               # 전문 에이전트
│   └── agent-*.md
├── hooks/                # 이벤트 훅 + 스크립트
│   ├── hook-*.md
│   └── *.sh
└── SPEC.md               # spec-only 일 때만

# 편집 → sync 플로우
vim plugins/<name>/...
bash .claude/scripts/sync-plugins.sh
git commit -m "..."

◆ 필수 (plugin.json v1.2)

  • name — prefix_feature
  • display — 한 줄 한글 설명
  • prefix — 등록된 prefix
  • version — 1.0 패턴
  • status — stable / spec-only / experimental
  • phase — 0 (현재 모두)

◆ 권장 추가 필드

  • dependencies.plugins — 의존 플러그인
  • entry_points.default_command
  • entry_points.core_skills
  • metadata.precedence — 로드 순서
  • metadata.token_estimate — 비용 예측

◆ 새 플러그인 만들기

  • cp -r plugins/_template plugins/<new>
  • plugin.json 의 name·prefix·display 수정
  • sync-plugins.sh 로 .claude/ 반영
  • validate-plugin-schema.py 로 검증
