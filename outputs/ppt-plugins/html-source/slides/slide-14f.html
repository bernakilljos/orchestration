"많이 깐다고 좋은 게 아니다 — 잘 쓰는 게 중요"
26 플러그인 다 알 필요 없음. 자주 쓰는 5~6 개만 익숙하면 끝.
슬래시 / 입력
외울 필요 없음. 채팅창에 / 입력하면 메뉴 자동 표시.
자연어로 시키기
"PPT 만들어" → Claude 가 알아서 /design_ppt 호출.
콤보 활용
/design_ppt + /arch-auto + /scout 조합 = PPT 한 권 자동.
모드 전환
/godmode (강력) · /devil (반박) · /brief (3줄) · /teacher (설명)
학습 누적
/learn (실패 저장) → /recall (다음 작업 자동 회피)

필요한 도구 없으면 plugins/_template 30분 → 자체 플러그인
