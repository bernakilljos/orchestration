왜 외부 플러그인을 만들었나

기본 Claude 만으로는 부족한 26개 도구 — 편의성 제공 + 필요시 직접 추가하는 확장성

"기본 Claude = 4 도구. 우리 + 26 = 30 도구.
없으면 plugins/_template 으로 직접 만들어 추가."
▸ plugins-guide · plugins/_template · 2026-05-08
▸ REASON 01
즉시 사용
설치 후 바로 26 슬래시 명령. 기본 Claude 가 못 하는 PPT 자동 생성 · 배포 · 검증 · 라우팅 다 됨.
26 ⚡
▸ REASON 02
확장 가능
plugins/_template/ 복사 → plugin.json 수정 → sync → 즉시 슬래시 명령. 새 도구 만드는 데 30분.
+ ∞
▸ REASON 03
팀 공유
한 명이 만든 플러그인 → 플러그인 sync 한 번 → 팀 전체 즉시 사용. plugins/ 가 SoT.
1 → N
▸ REASON 04
표준 준수
Anthropic 공식 plugin schema v1.2 + DK.method 호환. 다른 Claude 사용자와 공유 가능.
