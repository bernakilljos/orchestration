AI 시스템 6단계 — 우리는 4단계

Prompt → Agent → Orchestration → Automation (우리) → Autonomous → Platform — 1~3단계 위에 자동화 레이어 추가

▸ 단계 1
Prompt
사람이 하나씩 묻고 답 받기. ChatGPT 일반 사용 패턴.
▸ 단계 2
Agent
단일 AI 가 도구 사용. Claude Code 가 파일 읽고 코드 작성.
▸ 단계 3
Orchestration
여러 AI 가 협업. Claude 설계 + Codex 구현 + Haiku 검증.
▸ 우리 위치
▸ 단계 4
Automation
PC 꺼져도 24h 가동. Watchdog · Quota · Caching · Metrics 자동 운영.
▸ 단계 5
Autonomous
사람 개입 최소화. AI 가 목표 받고 스스로 분해·실행·검증.
▸ 단계 6
Platform
N개 팀 · N개 프로젝트 동시 운영. 글로벌 큐 · 멀티 테넌트.
▸ 우리가 4단계인 이유
3단계 (멀티AI) 완성 → 인프라 자동화 추가 (SQLite state · watchdog · quota·budget · prompt caching · metrics dashboard). 5단계는 codex-auto-global · ~/.claude/orca/ 글로벌 큐로 점진 진입.
▸ 다음 도약
5단계 = exec_offline + 자체 RAG (ai_rag spec-only). 6단계 = N팀 멀티 테넌트 (cost_youtube · /sync-team N×).
