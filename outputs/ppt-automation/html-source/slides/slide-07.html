한도 대기 + 예산 차단

API 사용량 한도와 일일 비용 상한 — 갑작스런 폭주 자동 방지

한도 대기
API 한도 도달 → 점점 길게 대기
"Codex 가 한도 침" → 10분 대기 → 또 침 → 20분 → 40분 → 2시간

◆ Backoff 단계 — 지수적 대기

  • 재시도 시각을 DB 에 기록

  • 다른 워커는 영향 없음 (격리)
  • 성공 시 카운터 0회로 복귀
예산 차단
일일 비용 상한 → 자동 차단
"오늘 누적 $50 도달" → 새 작업 차단 → 진행 중인 것만 완료 → 자정 초기화

◆ 설정 + 작동

  • 설정: route.py --set-daily-limit 50
  • 매 작업 전 누적 비용 vs 상한 비교
  • 초과 시 작업 차단 + 알림
  • 자정 (KST) 에 누적 비용 0 으로 초기화
