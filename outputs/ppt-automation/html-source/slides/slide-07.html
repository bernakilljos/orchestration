Quota Backoff + Budget Ceiling

API 한도와 일일 예산을 모두 관리 — 운영 비용 폭주 방지

Quota Backoff
API 한도 도달 → 지수 backoff
"Codex 가 quota 한도 침"
→ 처음 10분 대기 → 다시 시도 → 또 침 → 20분 → 40분 → 2시간

◆ Backoff 단계

10m
20m
40m
2h
  • state DB quota.retry_at 에 시간 저장
  • watchdog 가 시간 도래 시 자동 재시작
  • 다른 워커는 영향 없음 (개별 격리)
  • 성공 시 카운터 리셋 → 0회로 복귀
Budget Ceiling
일일 비용 상한 → 자동 차단
"오늘 누적 $50 예산 도달"
→ 신규 task 모두 차단 → 진행 중인 task 만 완료 → 자정 리셋

◆ 설정 + 작동

  • 설정: route.py --set-daily-limit 50
  • 매 task 시작 전 budget.spent vs limit 체크
  • 초과시 BUDGET_EXCEEDED exception
  • 워커 자동 종료 + slack 알림 (선택)
  • 자정 (KST) 에 budget.spent = 0
  • 기본값: 무제한 (limit 미설정)
