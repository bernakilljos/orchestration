◆ 무엇

  • 같은 prompt prefix 재사용 시 캐시
  • 5분 TTL (cache hit 시 자동 연장)
  • cache write: 1.25× input 단가
  • cache read: 0.1× input 단가 (90% off)

◆ 어떻게

  • system prompt + 큰 컨텍스트는 prefix 로
  • 변하는 부분 (변경 코드) 만 뒷부분
  • prompt_cache.py 헬퍼가 자동 처리
  • 2회+ 호출시 ROI 양수

◆ 활용 패턴

  • 리뷰: 코드 베이스 + 룰 (cache) + 변경 (no cache)
  • RAG: KB 청크 (cache) + 쿼리 (no cache)
  • 긴 문서 분석: 문서 (cache) + 질문 (no cache)

◆ 함정 · 주의

  • 1회성 호출엔 손해 (write 1.25× 만 발생)
  • 5분 TTL — 간격 길면 재 write
  • cache 키 변경시 (모델·버전) 전체 무효화
