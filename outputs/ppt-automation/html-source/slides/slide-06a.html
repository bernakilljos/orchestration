자동 복구 vs 의도된 정지

언제 자동으로 살아나고, 언제 의도적으로 멈추는가

◆ 자동 복구 케이스

  • Codex API 일시 장애 → 자동 재시도 (10m backoff)
  • quota 한도 도달 → backoff 후 재개
  • heartbeat timeout → kill + revive
  • OS 재부팅 → boot-time 자동 시작
  • 네트워크 일시 단절 → DNS 재시도 → 복구

◆ 멈추는 경우 (의도)

  • .claude/orca-stopped 파일 존재 → 영구 stop
  • budget ceiling 초과 (일일 상한) → 다음 날 재개
  • watchdog 자체 종료 (관리자 명령)
  • Claude Code 종료 후 5분 grace 후 stop
  • /orcauto-stop 슬래시 명령
