Watchdog · 죽은 워커 자동 부활

heartbeat 체크 → quota-aware 지수 backoff (10m → 20m → 40m → 2h) → 재시도

◆ 자동 부활 흐름

1워커가 매 30초 heartbeat 갱신 → state DB
2watchdog 가 60초 stale 워커 감지 → dead 마킹
3실패 사유 분석: quota · budget · crash
4quota 초과면 retry_at 계산 (지수 backoff)
5예약 시간 도래 시 자동 재시작 → heartbeat 복구
# watchdog 실시간 로그
[OK]   worker codex-1 heartbeat ✓ (30s ago)
[STALE] worker codex-2 stale 65s — checking
[DOWN]  worker codex-2 → quota exceeded
[BACKOFF] retry in 10m (tier-1) … 20m … 40m … 2h
[REVIVE] worker codex-2 restarted at 14:32

◆ 자동 복구 케이스

  • Codex API 일시 장애 → 재시도
  • quota 한도 도달 → backoff 후 재개
  • heartbeat timeout → kill + revive
  • OS 재부팅 → boot-time 자동 시작
